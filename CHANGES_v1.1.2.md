### 2. ✅ ДОБАВЛЕНО: Кнопка "Свободный график"

**Теперь при создании смены есть 3 кнопки:**

| График | Время | Продолжительность |
|--------|-------|-------------------|
| **5/2** | 08:00 - 17:00 | 9 часов |
| **2/2** | 10:00 - 22:00 | 12 часов |
| **Свободный** | Вы выбираете вручную | Любая |

**Как работает:**
1. Админ нажимает "Добавить смену"
2. Выбирает инженера
3. Выбирает дату смены
4. Нажимает на одну из трёх кнопок:
   - **5/2** → автоматически устанавливается 08:00-17:00
   - **2/2** → автоматически устанавливается 10:00-22:00
   - **Свободный** → появляются поля для ручного ввода времени
5. При выборе 5/2 или 2/2 время сохраняется, но можно изменить нажав "Свободный"
6. Сохраняет смену

```html
<button onclick="setSchedule('5/2')">5/2 (08:00-17:00)</button>
<button onclick="setSchedule('2/2')">2/2 (10:00-22:00)</button>
<button onclick="setSchedule('custom')">Свободный</button>
```

**Логика:**
```javascript
function setSchedule(type) {
    const date = document.getElementById('shiftDate').value;
    if (!date) {
        alert('Сначала выберите дату!');
        return;
    }
    
    if (type === 'custom') {
        // Показываем поля для ручного ввода
        document.getElementById('timeFieldsContainer').style.display = 'block';
    } else {
        // Автоматически заполняем время
        const times = {
            '5/2': { start: '08:00', end: '17:00' },
            '2/2': { start: '10:00', end: '22:00' }
        };
        // Заполнить поля времени
    }
}
```

### 3. ✅ ДОБАВЛЕНО: Удаление смен (только для админа)

**Функционал:**
- Админ может удалять любые смены
- Инженер НЕ может удалять смены
- При удалении смены удаляются:
  - Сама смена
  - Все отчёты привязанные к смене
  - Все фото из отчётов (физические файлы)
  - Все аудиофайлы из отчётов

**Интерфейс:**
- Кнопка удаления в модальном окне смены (только для админа)
- Подтверждение перед удалением
- Предупреждение о последствиях

```javascript
// Backend endpoint
app.delete('/api/shifts/:id', authenticateToken, isAdmin, async (req, res) => {
    // Получаем все отчёты
    // Удаляем смену (CASCADE удаляет отчёты)
    // Удаляем физические файлы фото и аудио
});
```

**Безопасность:**
- Только админ может удалять (middleware `isAdmin`)
- Каскадное удаление в БД (ON DELETE CASCADE)
- Проверка существования файлов перед удалением

### 4. ✅ ДОБАВЛЕНО: Управление пользователями

**Новая страница: `users.html`**

#### Функции:

**Просмотр пользователей:**
- Список всех пользователей в виде карточек
- Отображение роли (админ/инженер)
- Имя, фамилия, логин
- Email и описание
- Дата создания

**Создание пользователя:**
- Имя * (обязательно)
- Фамилия * (обязательно)
- Логин * (обязательно, латиница)
- Пароль * (обязательно, мин. 6 символов)
- Email (опционально)
- Роль * (инженер/админ)
- Описание (опционально)

**Редактирование:**
- Можно изменить все поля
- Пароль опционален при редактировании
- Если пароль не указан - остаётся старый

**Удаление:**
- Админ может удалить любого пользователя (кроме себя)
- Предупреждение: "Все смены и отчёты будут удалены!"
- Каскадное удаление всех связанных данных

#### Доступ:
```html
<!-- В navbar для админа -->
<a href="users.html" class="btn btn-outline-light btn-sm admin-only">
    <i class="bi bi-people-fill"></i> Пользователи
</a>
```

#### API Endpoints:
```javascript
GET    /api/users           // Получить всех пользователей
POST   /api/users           // Создать пользователя
PUT    /api/users/:id       // Обновить пользователя
DELETE /api/users/:id       // Удалить пользователя
```

**Валидация:**
- Username уникален (проверка в БД)
- Пароль минимум 6 символов
- Нельзя удалить самого себя
- Role: только 'admin' или 'engineer'

**Автоматическое формирование:**
- `full_name` = `first_name + last_name`
- Пароль хешируется (bcrypt, 10 раундов)

## 🐛 Известные проблемы и решения

### Проблема: Фото всё ещё не отображаются

**Возможные причины:**

1. **Старый кэш браузера**
   ```
   Ctrl + Shift + Delete → Очистить кэш
   Или Ctrl + F5 для жёсткой перезагрузки
   ```

2. **Неправильные пути к файлам**
   ```bash
   # Проверьте структуру
   backend/
   ├── uploads/
   │   ├── photos/
   │   │   ├── photo-123456.jpg
   │   │   └── photo-789012.jpg
   ```

3. **Права доступа**
   ```bash
   chmod 755 backend/uploads/photos/
   chmod 644 backend/uploads/photos/*
   ```

4. **Сервер не перезапущен**
   ```bash
   cd backend
   # Остановите (Ctrl+C)
   node server.js
   # Должно быть:
   # Server v1.1.2 is running
   # Photos: /api/photos/*
   ```

5. **Файлы не загрузились на сервер**
   ```bash
   # Проверьте размер файлов
   ls -lh backend/uploads/photos/
   # Если 0 байт - проблема с загрузкой
   ```

### Проблема: Кнопки графика не работают

**Решение:**
```
1. Сначала выберите ДАТУ
2. Потом нажимайте на кнопку графика
3. Проверьте Console (F12) на ошибки
```

### Проблема: Не могу удалить пользователя

**Причины:**
- Пытаетесь удалить себя (запрещено)
- Не админ (только админ может удалять)
- Пользователь не существует
