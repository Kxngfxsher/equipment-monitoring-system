# Изменения в версии 1.1 - Отчеты со сменами + Фото

## Что нового

### 1. **Создание отчета прямо в окне смены**
- Пользователь нажимает на смену и видит детали + кнопку "Создать отчет"
- Один отчет можно создать только из смены
- Если отчет уже создан, показывается его содержимое

### 2. **Поддержка фотографий в отчетах**
- В отчет можно загрузить несколько фото (до 5 штук)
- Фото + голосовая запись в одном отчете
- Просмотр всех фото в галерее

### 3. **Права доступа к отчетам**
- **Инженер**: может создать отчет только для своей смены, после создания - только просмотр
- **Админ**: может просматривать, редактировать и удалять любые отчеты

### 4. **Улучшенный интерфейс**
- Модальное окно для просмотра деталей смены
- Галерея фотографий в отчете
- Плеер для прослушивания аудио-отчета
- Индикация наличия отчета для смены

## Изменения в API

### Новые endpoint'ы

#### Получить отчет по shift_id
```http
GET /api/shifts/:id/report
Authorization: Bearer {token}

Response:
{
  "id": 1,
  "shift_id": 5,
  "user_id": 2,
  "equipment_id": "EQ-001",
  "status": "working",
  "description": "Все работает нормально",
  "audio_file": "audio-123456.mp3",
  "photo_files": ["photo-123456.jpg", "photo-789012.jpg"],
  "created_at": "2026-02-09 12:00:00"
}
```

#### Создать отчет с фото
```http
POST /api/reports/media
Authorization: Bearer {token}
Content-Type: multipart/form-data

Parameters:
- shift_id: 5
- equipment_id: "EQ-001"
- status: "working"
- description: "Описание"
- audio: [audio file] (optional)
- photos: [photo files] (optional, max 5)
```

#### Обновить отчет (только админ)
```http
PUT /api/reports/:id
Authorization: Bearer {token}
Content-Type: application/json

{
  "equipment_id": "EQ-002",
  "status": "maintenance",
  "description": "Обновленное описание"
}
```

#### Удалить отчет (только админ)
```http
DELETE /api/reports/:id
Authorization: Bearer {token}
```

#### Получить фото
```http
GET /api/photos/:filename
Authorization: Bearer {token}
```

## Как использовать

### Сценарий 1: Инженер создает отчет

1. Инженер заходит в систему
2. Видит свою смену в разделе "Смены"
3. Нажимает на смену → открывается окно с деталями
4. Нажимает "Создать отчет"
5. Заполняет форму:
   - Выбирает оборудование
   - Указывает статус
   - Пишет описание
   - Загружает голосовую запись (опционально)
   - Прикрепляет фото (до 5 штук)
6. Отправляет отчет
7. Больше не может редактировать (только просмотр)

### Сценарий 2: Админ просматривает отчеты

1. Админ заходит в систему
2. Видит все смены
3. Нажимает на смену с отчетом → видит индикатор
4. Открывает отчет, видит:
   - Информацию о смене
   - Данные оборудования
   - Описание
   - Аудио-плеер (если есть запись)
   - Галерею фото (если есть)
5. Может отредактировать или удалить отчет

---

## Ограничения

- Один отчет на одну смену
- Максимум 5 фотографий на отчет
- Размер аудио: до 10 МБ
- Размер фото: до 5 МБ каждое
- Инженер не может редактировать свой отчет после создания
- Только админ может удалять отчеты
