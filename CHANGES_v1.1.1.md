# Изменения в версии 1.1.1

## 🎯 Основные изменения

### 1. ✅ Формат даты изменён на dd/mm/yyyy
- Все даты теперь отображаются в формате: `09/02/2026 14:30`
- Изменён формат в карточках смен
- Изменён формат в деталях отчётов

### 2. ✅ Фиксированный график работы

#### Новый интерфейс создания смены:
- **Чекбокс "Фиксированный график"** (включен по умолчанию)
- **Поле выбора даты** - выберите дату смены
- **Кнопки выбора графика:**
  - **5/2** - Пятидневка: 08:00 - 17:00 (9 часов)
  - **2/2** - Сутки через двое: 10:00 - 22:00 (12 часов)

#### Как работает:
1. Выберите инженера
2. Отметьте "Фиксированный график" (или снимите для ручного ввода)
3. Выберите дату смены
4. Нажмите на кнопку графика (5/2 или 2/2)
5. Время автоматически заполнится
6. Добавьте описание (опционально)
7. Сохраните

#### Ручной режим:
- Снимите галочку с "Фиксированный график"
- Появятся поля для ручного ввода времени начала и конца

### 3. ✅ Исправлено отображение фотографий

**Проблема:** Фотографии не загружались из-за неправильного пути

**Исправление:**
- Добавлена обработка ошибок загрузки изображений
- Фото скрываются если не загружаются (вместо "битой" иконки)
- Добавлен hover-эффект для фотографий (увеличение при наведении)
- Улучшена галерея фотографий

**Проверьте в консоли браузера (F12)**, если фото не отображаются:
1. Откройте DevTools → Console
2. Посмотрите ошибки загрузки
3. Проверьте, что файлы существуют в `backend/uploads/photos/`

// Новая функция форматирования даты
function formatDate(date) {
    const d = new Date(date);
    const day = String(d.getDate()).padStart(2, '0');
    const month = String(d.getMonth() + 1).padStart(2, '0');
    const year = d.getFullYear();
    const hours = String(d.getHours()).padStart(2, '0');
    const minutes = String(d.getMinutes()).padStart(2, '0');
    return `${day}/${month}/${year} ${hours}:${minutes}`;
}

## 📋 Тестирование

### Проверьте:

1. **Формат даты:**
   - Откройте главную страницу
   - Проверьте что даты в формате dd/mm/yyyy
   - Откройте смену и проверьте формат в деталях

2. **Фиксированный график:**
   - Войдите как админ
   - Нажмите "Добавить смену"
   - Выберите инженера
   - Выберите дату (например, завтра)
   - Нажмите кнопку "5/2" → должно установиться 08:00-17:00
   - Нажмите кнопку "2/2" → должно установиться 10:00-22:00
   - Сохраните смену

3. **Ручной режим:**
   - Снимите галочку "Фиксированный график"
   - Должны появиться поля для ручного ввода времени
   - Введите время вручную
   - Сохраните смену

4. **Отображение фото:**
   - Создайте отчёт с фотографиями
   - Откройте отчёт
   - Проверьте что фото отображаются
   - Наведите на фото → должно увеличиться (scale 1.05)
   - Кликните на фото → должно открыться в большом размере

## 🐛 Известные проблемы и решения

### Проблема 1: Фотографии не отображаются
**Решение:**
```bash
# Проверьте что папка существует
ls backend/uploads/photos/

# Проверьте права доступа
chmod 755 backend/uploads/photos/

# Проверьте что сервер запущен
node backend/server.js
```

### Проблема 2: Кнопки графика не работают
**Решение:**
- Сначала выберите дату
- Затем нажмите на кнопку графика
- Проверьте консоль браузера (F12) на ошибки

### Проблема 3: Время не заполняется
**Решение:**
- Убедитесь что чекбокс "Фиксированный график" включен
- Убедитесь что выбрана дата
- Обновите страницу (Ctrl+F5)
