# Система контроля оборудования v1.1

## Что нового в v1.1? 🎉

### Отчеты прямо в сменах
- Пользователь нажимает на карточку смены
- Открывается окно с деталями смены
- Есть кнопка "Создать отчет" (если его еще нет)
- Или показывается готовый отчет

### Поддержка фотографий 📸
- Можно загрузить до 5 фото в один отчет
- Голосовая запись + фото в одном отчете
- Галерея для просмотра фото
- Клик по фото → увеличенный просмотр

### Права доступа 🔐
- **Инженер**: создает отчет для своей смены → после создания только просмотр
- **Админ**: полный контроль - может редактировать и удалять любые отчеты

### Улучшенный интерфейс ✨
- Карточки смен с индикаторами
- Зеленая граница = есть отчет
- Желтая граница = нет отчета
- Аудио-плеер для прослушивания записей
- Иконки Bootstrap Icons

## Как работать с системой?

### Для Инженера:

1. **Войдите** в систему (`engineer1` / `eng123`)
2. **Увидите** свои смены в виде карточек
3. **Нажмите** на смену → откроется окно
4. **Нажмите** "Создать отчет" (если его еще нет)
5. **Заполните** форму:
   - Выберите оборудование
   - Укажите статус (Исправно/Неисправно/Обслуживание)
   - Напишите описание
   - Загрузите аудио (опционально)
   - Прикрепите фото (до 5 штук)
6. **Отправьте** отчет
7. **Готово!** Отчет создан, теперь вы можете его только просматривать

### Для Администратора:

1. **Войдите** в систему (`admin` / `admin123`)
2. **Создавайте смены** для инженеров (кнопка "Добавить смену")
3. **Просматривайте** все смены и отчеты
4. **Редактируйте** любые отчеты
5. **Удаляйте** отчеты при необходимости
6. **Добавляйте** новых пользователей и оборудование

## Особенности v1.1

- ✅ **Один отчет на одну смену** - нельзя создать два отчета для одной смены
- ✅ **Максимум 5 фото** на один отчет
- ✅ **Аудио до 10 МБ**, фото до 5 МБ каждое
- ✅ **Инженер не может редактировать** свой отчет после создания
- ✅ **Только админ** может удалять отчеты
- ✅ **При удалении смены** удаляются все связанные отчеты и файлы

## API эндпоинты

### Новые в v1.1:

- `GET /api/shifts/:id/report` - Получить отчет по ID смены
- `POST /api/reports/media` - Создать отчет с аудио и фото
- `PUT /api/reports/:id` - Обновить отчет (только админ)
- `DELETE /api/reports/:id` - Удалить отчет (только админ)
- `GET /api/photos/:filename` - Получить фотографию

Полную документацию API см. в [CHANGES_v1.1.md](CHANGES_v1.1.md)

## Проблемы?

### Ошибка: "Report already exists for this shift"
- Можно создать только один отчет на смену
- Если нужно изменить - попросите админа

### Ошибка: "You can only create reports for your own shifts"
- Инженер может создавать отчеты только для своих смен

### Не могу загрузить фото
- Максимум 5 фотографий
- Каждое до 5 МБ
