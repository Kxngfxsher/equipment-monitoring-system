# Изменения v1.1.3 - Отчёт по всему оборудованию

## 🎯 Главное изменение

### БЫЛО:
- Отчёт = **1 оборудование** + статус + описание + фото
- Нужно выбирать оборудование из списка
- Один отчёт на смену

### СТАЛО:
- Отчёт = **ВСЁ оборудование** сразу
- Для **каждого** оборудования:
  - Свой статус (исправно/неисправно/требует обслуживания)
  - Своё описание
  - Свои фото (до 5 шт)
  - Своё аудио
- По умолчанию статусы берутся из последнего отчёта

## 📦 Новая структура БД

### Новая таблица: `equipment_reports`

```sql
CREATE TABLE equipment_reports (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    report_id INTEGER NOT NULL,           -- Ссылка на отчёт (смену)
    equipment_id TEXT NOT NULL,           -- ID оборудования
    status TEXT NOT NULL,                 -- Статус (исправно/неисправно/требует)
    description TEXT,                     -- Описание состояния
    photo_files TEXT,                     -- JSON с названиями фото
    audio_file TEXT,                      -- Аудиофайл
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (report_id) REFERENCES reports(id) ON DELETE CASCADE,
    FOREIGN KEY (equipment_id) REFERENCES equipment(equipment_id)
);
```

### Старая таблица `reports`
Теперь оставляет только общие данные отчёта:
- shift_id
- user_id
- priority
- created_at

## ✨ Преимущества

### 1. Полный обзор оборудования
- Не нужно выбирать оборудование - всё уже в списке
- Можно сразу увидеть всё оборудование

### 2. Статусы из предыдущего отчёта
- При создании отчёта автоматически подставляются статусы из последней смены
- Если оборудование новое - статус "исправно" по умолчанию

### 3. Индивидуальные фото/аудио
- Каждое оборудование может иметь свои фото и аудио
- Легче найти нужную информацию

### 4. История по каждому оборудованию
- Можно посмотреть историю конкретного оборудования
- Легче отслеживать проблемы
